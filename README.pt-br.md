## 🛠️ Meu processo

### 💻 Desenvolvido com

- Semantic HTML5
- CSS3
- CSS Flexbox
- CSS custom properties

### 📚 O que eu aprendi

Durante o desafio, pratiquei a criação de estruturas HTML semânticas, o uso do modelo de layout Flexbox e a aplicação de propriedades de alinhamento e espaçamento em CSS para consolidar o meu entendimento sobre layout e design responsivo. Também explorei e implementei transições CSS e propriedades personalizadas.

### 🚀 Desenvolvimento contínuo

Além de praticar o design responsivo e reforçar as propriedades que aprendi até agora, pretendo aprofundar meus conhecimentos em:
- Unidades relativas (`em` e `rem`)
- Funções do CSS, como `min()`, `max()` e `clamp()`
- Media queries
- `@font-face` at rule

### 📖 Recursos úteis

- [MDN Docs - Using custom properties](https://developer.mozilla.org/pt-BR/docs/Web/CSS/Guides/Cascading_variables/Using_custom_properties) - Me ajudou a entender a sintaxe e a aplicação prática das propriedades personalizadas
- [MDN Docs - var() CSS function](https://developer.mozilla.org/pt-BR/docs/Web/CSS/Reference/Values/var) - Me mostrou como efetivamente usar as propriedades personalizadas nas minhas regras CSS
- [MDN Docs - :root: CSS selector](https://developer.mozilla.org/pt-BR/docs/Web/CSS/Reference/Selectors/:root) - Esclareceu o conceito do seletor `:root`, complementando o meu entendimento e implementação de propriedades personalizadas
- [MDN Docs - transition CSS property](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transition) - Me ajudou a revisar rapidamente a sintaxe da propriedade `transition`

### 🤖 Colaboração com IA

Utilizei o ChatGPT exclusivamente para revisão e avaliação do meu código, usando o prompt fornecido pelo Frontend Mentor. O feedback me ajudou a identificar pontos fortes e fracos no meu código e a corrigir pequenos erros
